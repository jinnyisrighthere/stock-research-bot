# stock-research-bot
## 기획 의도 및 설계 철학 (Motivation & Design Philosophy)

본 프로젝트는 단순한 주가 요약이나 자동매매 봇이 아니라, **재무제표 분석 및 기업가치평가 이론을 실제 리서치 파이프라인으로 구현**하기 위해 설계되었습니다. 기존 범용 생성형 AI를 기업분석에 활용할 때 발생하는 한계를 극복하기 위해 다음 4가지 원칙을 시스템 구조에 반영했습니다.

1. **수치 계산과 정성 해석의 엄격한 분리 (AI Hallucination 통제)**
   - 범용 LLM에 기업분석을 일임하면 재무비율이나 DCF를 임의로 암산하다 수치 오류가 발생하거나, 근거 없는 추정을 사실처럼 서술하는 문제가 발생합니다.
   - 이를 방지하기 위해 5년·8분기 재무비율, 현금전환주기(CCC), ROIC, 발생액 비율(Accruals Ratio), DCF 및 Reverse DCF 역산 등 **모든 정량 연산은 100% 결정론적 Python 엔진(`engines/`)이 선행 처리**하여 단일 진실 공급원(`fact_sheet.json`)을 생성하고, AI 에이전트는 검증된 수치를 바탕으로 비즈니스 해석만 수행하도록 역할을 분리했습니다.

2. **1차 공시 원문(Primary Source) 기반의 사실·추론 구분**
   - 2차 뉴스 요약에 의존하지 않고 한국 금융감독원(OpenDART)과 미국 증권거래위원회(SEC EDGAR)의 법정 공시 데이터를 직접 수집합니다.
   - 모든 분석 문장에 `[공시사실]`, `[회사주장]`, `[시장컨센서스]`, `[증권사추정]`, `[AI추론]` 라벨링을 의무화하여, **경영진의 낙관적 가이던스와 공시로 확정된 객관적 팩트를 명확히 구분**해 읽을 수 있도록 설계했습니다.

3. **입체적 가치평가 및 기업 고유의 리스크 검증 내재화**
   - 단순 PER 비교나 표면적 손익 나열을 넘어, 현재 주가에 이미 반영된 시장의 기대 성장률을 역산하는 **Reverse DCF**, 투하자본수익률과 자본비용의 초과수익 스프레드(**ROIC - WACC**), GAAP과 Non-GAAP 괴리 및 이익의 질 평가, 그리고 투자논리를 깨뜨리는 **핵심 리스크의 선행지표(Early Warning)와 무효화 조건**까지 기관투자자(Buy-Side) 수준의 표준 프레임워크(`skills/`)로 체계화했습니다.

4. **매매 실행을 배제한 순수 의사결정 지원 도구**
   - 주문·체결 권한을 완전히 배제하고, 방대한 공시와 정량 지표를 **[정보 → 해석 → 투자적 함의]**의 3단 논법으로 구조화하여 *"현재 주가에서 왜 매수해야 하는가, 혹은 왜 피해야 하는가"*에 대한 냉정한 판단 근거를 제공하는 데 목적을 두었습니다.
